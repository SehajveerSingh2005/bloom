# Agent logo sources

Retrieved 2026-11-04. These are vendor assets, replacing the earlier Simple Icons
copies. Trademarks remain with their respective owners.

- `claude.svg`: orange symbol path from the official inline Claude wordmark at
  [claude.com](https://claude.com/), unchanged `d` and `#D97757` fill. The viewBox
  isolates its original 125 × 125 symbol area; no geometry was redrawn.
- `opencode.svg` / `opencode-light.svg`: original dark/light square SVG downloads
  embedded in [OpenCode's brand page](https://opencode.ai/brand), from
  `src/asset/brand/opencode-logo-{dark,light}-square.svg`. Original multicolor fills,
  viewBox, masks and paths are preserved.
- `codex.svg` / `codex-light.svg`: white/black mono Blossom SVGs from
  [OpenAI's official logo bundle](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip),
  files `OpenAI-{white,black}-monoblossom.svg`. These identify the OpenAI integration;
  they are OpenAI marks, not a separately claimed Codex product logo. The viewBox
  crops the bundle's outer clearspace for legibility at 20px; paths are unchanged.

SVG files render directly as images. CSS selects the provided light/dark versions
without recoloring or flattening the vendor artwork into a monochrome mask.

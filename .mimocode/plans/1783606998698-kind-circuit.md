# Startup Animation Plan — Bloom Splash Screen

## Goal
Add a cinematic first-launch + update splash: Bloom logo scales up center-screen, pulses, rotates, then scales down while notch components launch behind it. Also merge volume + brightness overlays into a single window to cut one WebView2 renderer process and its memory overhead.

## Two Changes in One

### Change 1: Merge Volume + Brightness Overlays
Currently two separate windows (`volume-overlay` at left edge, `brightness-overlay` at right edge). Merge into one `overlay` window that repositions itself based on which overlay is active.

**Why this matters for splash:** The merged overlay window becomes the splash window too — it goes fullscreen for the splash animation, then repositions to left/right edge for overlay duty. Zero new windows created.

### Change 2: Splash on First Launch + After Updates
Splash shows on **first launch after installation** AND **after every update**. Each overlay window spawns a separate Chromium renderer process — merging two into one cuts memory usage and startup overhead. The splash uses the same merged window so no extra process is needed for the intro animation.

**Detection:**
- First launch: `bloom-first-run` in localStorage is null (existing key at `App.tsx:416`)
- After update: Store `bloom-app-version` in localStorage, compare with `getVersion()` on mount — if different, show splash and update the stored version

## Part B: Splash Screen

### Animation Sequence (~3.5s)
```
Phase 1 (0-0.8s):   Logo fades in + scales up (0 -> 1.0) with spring
Phase 2 (0.8-1.6s): Logo pulses (scale oscillates 1.0 -> 1.15 -> 1.0)  
Phase 3 (1.6-2.8s): Logo starts continuous rotation (0 -> 360deg loop)
Phase 4 (2.8-3.5s): Logo scales down (1.0 -> 0.3) + fades out while still rotating
                     → simultaneously, main notch window becomes visible
```

### Detection Logic (in Overlay.tsx)
```
On mount:
  1. Check localStorage "bloom-first-run" (null = first launch)
  2. Check localStorage "bloom-app-version" vs getVersion() (mismatch = update)
  3. If firstRun OR versionMismatch:
     a. Set mode to 'splash'
     b. Show overlay window fullscreen
     c. Play animation sequence
     d. On complete: emit 'splash-done' event, set mode to 'idle'
     e. Set localStorage "bloom-first-run" = "done"
     f. Set localStorage "bloom-app-version" = current version
  4. If neither (normal launch):
     a. Skip splash entirely
     b. Listen for volume/brightness events normally
```

### Splash in Overlay.tsx
```tsx
// Inside the merged Overlay component
const [mode, setMode] = useState<'idle' | 'volume' | 'brightness' | 'splash'>('idle');

useEffect(() => {
  const firstRun = localStorage.getItem("bloom-first-run") === null;
  const storedVersion = localStorage.getItem("bloom-app-version");
  
  getVersion().then((currentVersion) => {
    const isUpdate = storedVersion !== null && storedVersion !== currentVersion;
    
    if (firstRun || isUpdate) {
      setMode('splash');
      invoke('set_splash_fullscreen', { fullscreen: true });
      
      // Store version for future update detection
      localStorage.setItem("bloom-app-version", currentVersion);
    }
  }).catch(() => {});
}, []);

// After splash animation completes:
const onSplashComplete = () => {
  localStorage.setItem("bloom-first-run", "done");
  setMode('idle');
  invoke('set_splash_fullscreen', { fullscreen: false });
  emit('splash-done');
};
```

### Splash Rendering

### Rust-side Splash Commands (in commands.rs)
```rust
#[tauri::command]
pub fn set_splash_fullscreen(app: AppHandle, fullscreen: bool) {
    if let Some(win) = app.get_webview_window("overlay") {
        if fullscreen {
            if let Ok(Some(monitor)) = win.primary_monitor() {
                let size = monitor.size();
                let pos = monitor.position();
                let _ = win.set_position(PhysicalPosition::new(pos.x, pos.y));
                let _ = win.set_size(PhysicalSize::new(size.width, size.height));
                let _ = win.show();
            }
        } else {
            // Revert to overlay position (handled by sync_overlays)
            sync_overlays(&app);
        }
    }
}
```
